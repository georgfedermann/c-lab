# C Lab
Learning C and exploring computer systems from the bottom up.

This repository documents my exercises, experiments, and discoveries while working through
- K. N. King - C Programming: A Modern Approach
  Learning the C programming language, including pointers, memory management, data structures, and program organization
- Bryant & O'Hallaron - Computer Systems: A Programmer's Perspective
  Understanding how C programs are compiled, represented, and executed,
  from machine instructions and memory hierarchies to processes and virtual memory.
- Kerrisk - The Linux Programming Interface
  Exploring Linux system programming, including system calls, file I/O, processes,
  signales, interprocess communication, threads, and networking.

# Objectives
Develop a deeper understanding of:
- The C programming language
- Compilation, linking, and assembly language
- Computer architecture and memory organization
- Operating systems and the Linux kernel interface
- Processes, concurrency, and interprocess communication
- Systems programming and performance

# Environment
- Lenovo ThinkPad T14 Gen 1 AMD (clab)
- Linux Mint
- GCC, GDB, Neovim, tmux

# Repository Structure
- king/ - C language exercises and programming projects
- csapp/ - computer systems exercises and experiments
- tlpi/ - Linux systems programming exercises and experiments
- experiments/ - independen investigatoins and explorations

# Approach
Learn by implementing, experimenting, debugging, and investigating what happens beneath the abstractions.

Start with C fundamentals, progressively explore machine-level behavior,
and apply this knowledge to Linux systems programming.
